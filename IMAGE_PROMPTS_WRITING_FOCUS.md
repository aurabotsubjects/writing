# Writing Focus — Image Prompts (all lessons)

These pictures give every Writing Focus lesson its look: a **week banner** at the top of each lesson, prompt and Term Map, a **term cover**, and **five shared pictures** used in the ▶ Present lesson slides (I Do · We Do · You Do · Learning · Before we go).

They use the same black-and-white manga ink style as Morninglight 2027 and the Writing Process pictures. The app adds all the colour and all the words.

## How to use this file

1. **Use the same character sheet as the Writing Process** (`char-writers.png`, prompt A1 in `IMAGE_PROMPTS_WRITING_PROCESS.md`). Make it first if you haven't.
2. **One new ChatGPT chat per term.** Attach the character sheet. Then paste one prompt at a time — each one is complete.
3. If colour or words creep in, reply: *"Redo it strictly black-and-white, with no text, letters or numbers anywhere."*
4. **Save each picture with the exact file name** into the folder shown (`.png`, `.jpg` or `.webp` all work). Reload the app — the "Image to come" box is replaced automatically, with a slow zoom.
5. **Order of priority:** the five shared pictures first (they appear in all 200 lessons), then the current term's ten weeks, then the term covers.
