# Writing Process: Image Prompts

**Writing Focus → Writing Process tab** · FILL · FIND · SHAPE · SHARE

These images use the same look as Morninglight 2027: black-and-white manga / graphic-novel ink. The app adds the colour itself, with a coloured frame, word and band for each stage. Because the art is pure ink, the **colour-in wall cards** print as real colouring pages.

## How to use this file

1. **Make the character sheet first** (Section A). Do it in its own ChatGPT chat and save it.
2. **Start one new ChatGPT chat for all the scenes.** Attach the character sheet so the two students look the same in every picture.
3. **Paste one prompt at a time.** Each prompt is complete, because the style instructions are already inside it.
4. If colour or words creep in, reply: *"Redo it strictly black-and-white, with no text, letters or numbers anywhere."*
5. **Save each image with the exact name shown** into `Writing Warmup/images/process/v2/`. `.png`, `.jpg` and `.webp` all work. Reload the app and the "Image to come" box is replaced by the picture, with a slow zoom.
6. Don't put any words in the pictures. The app writes the stage words and questions over and around the art, so the text is always correct and easy to change.

## The style block (already inside every prompt)

```
STYLE: Black-and-white manga / graphic-novel ink illustration. Thick confident black outlines, dramatic high-contrast lighting, large solid-black shapes, soft grey airbrushed gradients, fine halftone shading, light rays and speed lines, dynamic cinematic camera angles. Setting: a bright, modern New Zealand primary school classroom and its surroundings. Strictly monochrome (black, white and greys only). Hand-inked look, not photorealistic, not 3D, not painterly. Child-appropriate, warm and encouraging. Absolutely no text, letters, numbers, captions, speech bubbles, signatures or watermarks anywhere in the image, including on pages, books, screens and posters (show writing as squiggly lines only).
```
